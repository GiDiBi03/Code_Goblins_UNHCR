4FASE 3 — Medidas de Reviews (tabla revisiones)~15 min

Se reutilizan Count Revisiones y Avg Uncertainty Reviewed.

Por qué: la tasa de desacuerdo es el indicador central. El reto pide reportarla con intervalo de confianza (Wilson), porque con pocas revisiones un 50% puede significar casi cualquier cosa. Comparar Blind Inclusion Rate con Recorded Inclusion Rate (Reviewed) muestra si, a ciegas, los caseworkers incluyen más o menos que la decisión registrada.
Dónde: Panel Datos → clic derecho en revisiones → Nueva medida.
Blind Include =
CALCULATE([Count Revisiones], revisiones[EligibilityTarget2] = "INCLUSION")
Blind Exclude =
CALCULATE([Count Revisiones], revisiones[EligibilityTarget2] = "EXCLUSION")
Agreements =
CALCULATE([Count Revisiones], revisiones[Agreement] = "Agrees")
Disagreements =
CALCULATE([Count Revisiones], revisiones[Agreement] = "Disagrees")
Disagreement Rate =
DIVIDE([Disagreements], [Count Revisiones])
Disagreement Rate CI Low =
VAR k = [Disagreements]
VAR n = [Count Revisiones]
VAR z = 1.96
VAR p = DIVIDE(k, n)
VAR c = (p + z * z / (2 * n)) / (1 + z * z / n)
VAR h = z * SQRT(p * (1 - p) / n + z * z / (4 * n * n)) / (1 + z * z / n)
RETURN
    IF(n > 0, MAX(0, c - h))
Disagreement Rate CI High =
VAR k = [Disagreements]
VAR n = [Count Revisiones]
VAR z = 1.96
VAR p = DIVIDE(k, n)
VAR c = (p + z * z / (2 * n)) / (1 + z * z / n)
VAR h = z * SQRT(p * (1 - p) / n + z * z / (4 * n * n)) / (1 + z * z / n)
RETURN
    IF(n > 0, MIN(1, c + h))
Blind Inclusion Rate =
DIVIDE([Blind Include], [Count Revisiones])
Recorded Inclusion Rate (Reviewed) =
DIVIDE(CALCULATE([Count Revisiones], revisiones[EligibilityTarget] = "INCLUSION"), [Count Revisiones])
Avg Uncertainty Disagreements =
CALCULATE([Avg Uncertainty Reviewed], revisiones[Agreement] = "Disagrees")
Reviews with Note =
CALCULATE([Count Revisiones], NOT ISBLANK(revisiones[nota]))
Verificación
  • Blind Include + Blind Exclude = Count Revisiones
  • Agreements + Disagreements = Count Revisiones
  • Prueba de Wilson: con 1 desacuerdo de 2 revisiones, el IC da 9.5% – 90.5%
Formato: todas las Rate y los dos CI en Porcentaje con 1 decimal.
